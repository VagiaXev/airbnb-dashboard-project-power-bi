# Airbnb Dashboard Project

This project involves creating an Airbnb dashboard using Power BI. The dashboard provides key statistics and insights regarding listings, hosts, booking, and reviews, and is designed to aid in strategic decision-making.

The project was developed as part of the course "Power BI: A Guide to Data Visualization & DAX" offered by Data Tutor under the guidance of Alexandra Athanasakou.

## Contents

- **pbix/**: It contains the Power BI report with the dashboard.
- `Airbnb Listings Reviews and Bookings Dashboard (DV Project).pbix`
- Download the Power BI Dashboard: You can find the full .pbix in the Releases section.

- **presentation/**: It contains the PowerPoint presentation with the conclusions from the analysis
- `Airbnb_Dashboard_Insights.ppt`

## Instructions for Use

1. **Opening the Power BI Report**:
- Open the file `Airbnb Listings Reviews and Bookings Dashboard (DV Project).pbix` in Microsoft Power BI Desktop.

2. **Summary of Results**:
- Please refer to the PowerPoint presentation for a summary of the analysis findings.

## About the Project

The project involves the creation of an analytical dashboard that provides insights into accommodations, hosts, bookings, and reviews on the Airbnb platform. The dashboard has been designed to meet business needs for strategic analysis.

This project is part of the course "Power BI: A Guide to Data Visualization & DAX" (https://datatutor.gr/courses/data-visualization-dax-microsoft-power-bi/) offered by Data Tutor and led by Alexandra Athanasakou (https://datatutor.gr/your-data-tutor).

## Data Source

The data used in this project is sourced from Airbnb and can be accessed through the following link: - [Inside Airbnb](https://insideairbnb.com/get-the-data/) The data is made available by Inside Airbnb and is used here under the terms of their dataset access policy. Please refer to the [Inside Airbnb Data Terms] (https://insideairbnb.com/get-the-data/) for more details about the data and its usage.
